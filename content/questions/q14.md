A sail maker’s associate wants a Cowork task to pull order status from the firm’s supplier portal, which has no connector, and also to read the shared Drive folder of orders. She is tempted to use full computer use for both because it reaches everything.

**Which reach paths are most appropriate?**

A. Computer use for both, since it is the most flexible and reaches everything.
B. Browser for both, since a browser can open the Drive folder as well.
C. Computer use for the portal and a connector for Drive, to keep the portal stable.
D. Connector for Drive, and the browser path for the portal, ahead of computer use.

## Explanation

Use the most structured tool that can do the job: connector before browser, browser before full computer use. Drive has a connector; the portal needs a browser.
