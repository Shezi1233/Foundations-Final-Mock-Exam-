A freelance translator wants a rule that every reply gives the answer before the explanation, and a glossary that should be used only inside one client’s work. She is deciding where each belongs among standing instructions, memory and a project.

**Which TWO statements are correct? (Select TWO)**

A. The answer-first rule is stable, so it belongs in standing instructions.
B. The client’s glossary is reference material for one stream of work, so it belongs in that client’s project knowledge.
C. Her evolving preferences belong in standing instructions, since memory is only for stable rules.
D. Any one-off question should get its own project so that nothing carries over.

## Explanation

Instructions for stable rules, memory for evolving context, projects for scoped work. Putting one in another’s place is the most common configuration mistake.
