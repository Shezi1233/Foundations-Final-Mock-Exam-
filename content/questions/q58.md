A tool-hire firm’s analyst replaces each customer name with a label such as “Customer 17” and keeps a spreadsheet mapping labels back to names. She uploads the labelled file to an AI route nobody has approved, saying the data is now anonymized and therefore green.

**Which statement is most accurate?**

A. The data is anonymized, because no name appears in the uploaded file.
B. The data is pseudonymized; because the mapping can reconnect it, it keeps its tier, and the route still needs approval.
C. The data is green, since the mapping file is stored in a separate folder from the upload.
D. The data is pseudonymized, so it drops one tier and may use any route.

## Explanation

If anyone still holds the list that maps labels back to people, the data is pseudonymized, not anonymized, and keeps its tier. The route question is separate and still open.
