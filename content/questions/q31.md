An antique dealer’s associate pastes a client’s private valuation report into a Claude Project and says, “It is in a Project, so it is approved for this.” A colleague adds that the code-execution sandbox also makes any file safe.

**Which statement is most accurate?**

A. A Project is a permission shortcut, so approval is settled once files are inside.
B. A sandbox is an approval boundary, so any file placed in it is safe.
C. Incognito is zero retention, so the report would be safe to use there too.
D. A Project is a route; approval for this data is the real question.

## Explanation

Routes and controls answer narrower questions than authorization. A sandbox is an execution boundary, incognito is not zero retention, and a Project is only a route.
