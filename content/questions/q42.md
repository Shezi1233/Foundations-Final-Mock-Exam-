A fish market’s associate has Claude write and run code that totals daily catch by species from 25 exports. The answer looks right, and she wants to verify it before it goes into a price list.

**Which TWO checks are rungs of the verification ladder? (Select TWO)**

A. Run it on one slice whose answer she already knows.
B. Ask Claude to explain in plain English what the code did.
C. Check that the code uses the most popular library she can find.
D. Read the code line by line for syntax errors before she trusts it.

## Explanation

The ladder is known-answer test, reality questions, plain-English replay, adversarial pass, cross-model check. You never need to read syntax.
