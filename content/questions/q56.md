A tax firm’s associate runs a Cowork cloud task that produces a finished client tax-computation PDF. She leaves the file in the session and shares the platform link with the client. Three weeks later the client asks where the PDF is in the firm’s matter folder, and nobody can find it there.

**Which diagnosis is most accurate?**

A. The file sat in tier 1 and was wiped when the task ended, so it should have been saved in tier 2.
B. The file stayed in tier 2, the vendor’s custody, so it never reached the firm’s own system of record; it should have exited to tier 3.
C. The file reached tier 3 automatically, but the platform link expired.
D. The file was never created, since cloud tasks can only describe documents.

## Explanation

Finished work exits the platform. Tier 2 is safe but is the vendor’s custody. The firm’s records live in tier 3, such as the document management system, from which it should also be shared.
