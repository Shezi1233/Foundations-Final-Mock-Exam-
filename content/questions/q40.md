A brick kiln’s associate wants to enable a connector from a well-known publisher. The workflow only reads the shared drive, but the connector’s setup asks for write access to the whole drive. She is unsure whether to enable it or decline.

**Which message is most appropriate to send to the admin?**

A. “Can I use this connector, please, since it comes from a well-known publisher?”
B. “Please approve every connector from this publisher in advance, so I need not ask.”
C. “It wants write access but my workflow only reads; can that be narrowed?”
D. “I have enabled it for now; please tell me if there is any problem.”

## Explanation

A good escalation names the unresolved question. Reach must be proportionate to the job, so start read-only and ask for narrower scope.
