A hot-air-balloon operator’s manager says Claude’s weekly safety summary “missed the point” and “uses the wrong tone”. The associate wants to turn each reaction into an instruction that names a lever.

**Which TWO instruction-lever pairs are correct? (Select TWO)**

A. “Missed the point”: state the one question the summary must answer, in the prompt.
B. “Wrong tone”: add a tone constraint to the standing instructions for every draft.
C. “Missed the point”: switch the Project to a model with a stronger writing style.
D. “Wrong tone”: replace the knowledge-base file with a longer version of itself.

## Explanation

Reaction to instruction: missed point maps to the prompt; a tone rule that applies every time maps to standing instructions. A model switch or longer knowledge file names the wrong lever.
