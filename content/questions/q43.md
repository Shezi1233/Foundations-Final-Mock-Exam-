A tax-advice firm wants Cowork to read clients’ signed engagement letters from a local folder via Claude Desktop. The letters contain personal financial data, and the firm’s contract restricts processing to approved systems. The associate says it should be fine since the folder is on her own machine.

**What is the most appropriate step?**

A. Proceed, since a local file read through the bridge is not processed in the cloud.
B. Proceed in Skip mode so that approvals do not slow the run.
C. Strip the clients’ names and carry on, since that always makes the data safe.
D. Stop and get the written compliance answer first; availability is not permission.

## Explanation

A cloud session that reads a local file through the Desktop bridge processes its contents in the cloud. For restricted data, get the written answer before the upload.
