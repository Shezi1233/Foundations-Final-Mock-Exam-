A yarn shop’s associate built a useful “pattern-pricing” Skill in Claude.ai. Her niece uses a different tool that also reads the SKILL.md format and wants it. A colleague who built a custom GPT for the same task says Skills are locked to Claude.

**Which statement is most accurate?**

A. Skills are locked to Claude, just like custom GPTs and Gems.
B. A basic SKILL.md travels to other tools that read the open standard.
C. Skills only work if the other tool is also made by Anthropic.
D. Custom GPTs travel to other tools, but Skills never leave Claude.

## Explanation

Agent Skills is an open standard, so a basic SKILL.md travels. Custom GPTs and Gems live only inside their own products.
