A knitting-pattern firm’s associate corrects a wrong yarn-weight detail, and Claude replies, “You’re right, my mistake.” The next day she opens a fresh chat with memory turned off and Claude repeats the same error. She concludes that Claude is faulty.

**Which explanation is most accurate?**

A. The correction was written into the weights, but a fault stopped it loading in the new chat.
B. Using a model changes nothing inside it; the correction only sat in that chat’s context window.
C. Claude learns from a correction only after the same correction has been given three times.
D. The weights are reset every night, which erased the correction.

## Explanation

Inference changes nothing inside the model. The correction helped only while it sat in that chat’s context window; a new chat starts from the identical frozen weights.
