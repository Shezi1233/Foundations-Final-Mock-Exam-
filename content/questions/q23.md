A vinyl-record pressing plant’s associate asks Claude to write and run a script that renames and moves 500 label-artwork files into client folders. She has no backup, and files overwritten in place cannot be recovered. The script will run on her own machine.

**Which instruction should she add first?**

A. “Don’t change anything yet; list every operation you would perform and wait for approval.”
B. “Run it on the whole drive so that stray artwork files are caught as well.”
C. “Overwrite the old files with the new names so that no duplicates remain.”
D. “Run it now and tell me afterwards if anything went wrong.”

## Explanation

A dry run shows every change before it happens, turning a misunderstanding into words instead of lost files. The other options widen the blast radius or act first.
