A mushroom farm’s analyst has put a seven-step month-end close, which must run in a fixed order, into the Project’s standing instructions as one long paragraph. Claude now skips steps four and five when chats run long. The analyst thinks the instruction needs stronger wording.

**Where does the correction belong?**

A. In the knowledge base, as a reference file with the same paragraph.
B. In the standing instruction, with the paragraph rewritten more firmly and in capitals.
C. In a Skill, since an ordered set of steps is a procedure.
D. In a fresh Project for each month, so the paragraph is read afresh.

## Explanation

Rule, reference or procedure? An ordered sequence of steps is a procedure, and procedures belong in a Skill. Wrong home, not weak wording, is the problem.
