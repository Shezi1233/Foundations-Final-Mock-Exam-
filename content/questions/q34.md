A postal sorting office’s associate schedules a Cowork task each Monday. This week the run log shows that it fired, started, finished and produced a file. When she opens the file it contains only the heading and “No new items”, though she knows twelve parcels arrived.

**What does the run log prove?**

A. Only that the mechanism ran; it does not show the work succeeded.
B. That the work succeeded, since the file exists and has the right heading.
C. That the task is unsafe and should switch from Auto to Skip.
D. That “no new items” is always valid, so she can ignore the file.

## Explanation

Ran is not the same as worked. Runtime evidence shows the mechanism ran; only outcome evidence shows success. Check the output against what you know.
