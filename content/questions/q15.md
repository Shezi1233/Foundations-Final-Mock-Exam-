A whisky distillery’s associate has a Skill that drafts the monthly excise summary. It worked for a year. This month it applies last year’s duty rate, and a colleague reports that the layout no longer matches the revised form. Nobody edited the Skill, and fresh chats behave the same.

**What should she do first?**

A. Rename the Skill and re-upload it so that it loads more reliably.
B. Start a fresh chat for each run so that earlier months cannot interfere.
C. Re-read the Skill against how the work is done today and update it.
D. Move the whole summary into a script, since scripts never go stale.

## Explanation

“It used to work, now it doesn’t” with no edits and no error is stale configuration. The skill did not change; the world did. Re-read it against current practice. Fresh chats do not help.
