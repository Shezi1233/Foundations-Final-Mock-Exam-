A kayak-rental firm’s associate wonders why Claude loads only part of her Skill until a request matches. She asks which parts of a SKILL.md are always loaded and which are opened later.

**Which TWO statements are correct? (Select TWO)**

A. The name and description are always loaded, to decide relevance.
B. The instructions in the body are opened only when a request matches.
C. The whole file is loaded in every chat, so it should be kept short.
D. Extra files in folders are loaded first, before the name and description.

## Explanation

Progressive disclosure: only the name and description stay loaded (level one). The body opens when the request matches (level two). Extra folders are read only when needed (level three).
