A saffron grower’s associate asks Claude, in the middle of a long chat about export prices, for a one-page buyer guide that she will edit and send to wholesalers. The guide appears as a long message in the scroll, and she keeps scrolling to find it after each change.

**What should she do?**

A. Ask for the guide as an artifact or document, separate from the chat.
B. Ask Claude to repeat the whole guide at the end of every reply.
C. Copy the guide into memory so that Claude keeps it ready for her.
D. Start a new chat for each edit so the guide appears at the top.

## Explanation

Chat is for conversation; finished work belongs in an artifact or document, a separate object you can revise in place.
