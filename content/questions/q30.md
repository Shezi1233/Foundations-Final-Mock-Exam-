A sugar refinery’s associate reads that a chatbot “leaked its system prompt” and asks whether this means the model has some secret memory. She wants to understand what a system prompt actually is.

**Which explanation is most accurate?**

A. It is ordinary text first in the window, so the model can repeat it.
B. It is a hidden database inside the weights that the model must look up.
C. It is a memory the model builds up about each user over many chats.
D. It is code that runs separately and can never be repeated in any reply.

## Explanation

The system prompt is just text the product places first in the context window. Someone persuaded the model to repeat text that was in its window all along.
