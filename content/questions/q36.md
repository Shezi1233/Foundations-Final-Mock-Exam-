A lumber yard’s associate uses ChatGPT for two clients whose matters are confidential from each other. She worries that the assistant’s wider memory about one client might surface in the other client’s chats.

**Which setup is most appropriate?**

A. Default project memory, since a project always isolates its chats.
B. One project for both clients, with each client named in the instructions.
C. Standing instructions telling the assistant to forget the other client.
D. A separate project for each client, set to project-only memory.

## Explanation

A project organises; project-only memory is what turns it into a real boundary that keeps outside memories out.
