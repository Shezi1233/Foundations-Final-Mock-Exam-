A coffee roastery’s associate wants Claude to write code that cross-checks 30 days of roast logs against green-bean stock counts. Before trusting it, she plants one fake discrepancy that she knows about in a copy of the logs and runs the script.

**What does this test achieve?**

A. A known-answer test: if it finds her plant, the other findings are more believable.
B. A speed test: it shows how fast the code runs on a month of logs.
C. An adversarial pass: it proves the code has no hidden errors in the logs.
D. A cross-model check: it compares the result across two different AI families.

## Explanation

Adding one known error and seeing whether the code finds it is the known-answer test in its most elegant form.
