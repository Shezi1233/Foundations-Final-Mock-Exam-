A tuition centre’s manager lists four tasks and asks which are code problems rather than answer problems: (A) summarise one news article for the newsletter; (B) find which of 80 contracts have a non-standard cancellation clause; (C) judge whether a new course idea is any good; (D) work out which families owe fees from a payments spreadsheet, where a wrong figure means a wrong demand.

**Which TWO are code problems? (Select TWO)**

A. Summarise one news article for the newsletter.
B. Find which of 80 contracts have a non-standard cancellation clause.
C. Judge whether a new course idea is any good.
D. Work out which families owe fees from a payments spreadsheet.

## Explanation

Any one of Volume, Precision, Repetition or Files makes it a code problem. Eighty contracts is Volume and Files; a fee spreadsheet where a wrong digit matters is Precision and Files. A summary and a judgment call are answer problems.
